## Quickstart: Create and deploy an agent with the standard harness

> [!Note]
> This article describes features used in agents or agent flows powered by the standard harness.

When you create an agent, you can describe what you want your agent to do in your own words.

The example scenario in this quickstart creates an agent called Copilot Studio Guide to help users learn about Copilot Studio based on knowledge from the official Copilot Studio documentation.

1. Sign in to Copilot Studio, or sign up. You land on the Home page.
2. Turn off New experience and select Submit to dismiss the Feedback panel. The Home page for agents powered by the standard harness appears.
3. Optionally, change the primary language, solution, and schema name for your agent.
4. Enter a brief description of what you want your agent to do. For example, "Help users learn how to create agents with Copilot Studio." The description can have up to 1,024 characters.
The Overview page for your agent appears.
![](/Images/home-page-describe-your-agent.png)
5. Once Copilot Studio finishes provisioning your agent, you can change its name, description, and instructions. You can add triggers, knowledge sources, tools, and suggested prompts. Remember to test your changes as you go. For example, add the official Copilot Studio documentation as a knowledge source:
   1. In the Knowledge section, select Add next to the suggestion for [Copilot Studio](https://learn.microsoft.com/copilot-studio)
      1. Select Add, and then select Add to agent.
6. Test and improve your agent.
